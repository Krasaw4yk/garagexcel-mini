# GARAGEXCEL MINI ROZSZERZONE

Program do prowadzenia napraw, historii pojazdów, klientów, zakupów części i raportów warsztatu. Dane są przechowywane lokalnie. Wersje Windows 10/11 mogą też pracować na wspólnej bazie w sieci warsztatu.

## Pobieranie

W sekcji [Releases](../../releases) wybierz instalator dla swojego systemu.

| System | Wersja | Tryby |
| --- | --- | --- |
| Windows 10/11 64-bit | 3.1.3 | SOLO, LAN, DEMO |
| Windows 10 32-bit | 3.1.2 | SOLO, LAN, DEMO |
| Windows XP SP3 32-bit | 3.1.4 | SOLO, DEMO |

Windows 10 wymaga wersji 2004 lub nowszej. Instalator XP uruchom z prostej ścieżki, np. C:/GARAGEXCEL_XP. Zalecana rozdzielczość na XP to co najmniej 1024×768.

## DEMO i licencja

Każdy może pobrać i zainstalować program. **DEMO działa bez klucza** i pozwala wypróbować formularze na przykładowych danych. Ponowne uruchomienie DEMO przywraca przykładową bazę.

**Do pracy na własnych danych potrzebna jest licencja od autora.** Opłata jest jednorazowa. Skopiuj kod komputera z ekranu aktywacji, przekaż go autorowi prywatnie i wczytaj otrzymany plik GXLIC lub klucz. W trybie LAN licencję wczytuje się na komputerze głównym, a kolejne stanowiska się z nim parują.

Podaj wersję programu, wersję Windows i kroki prowadzące do problemu. Klucze, kody komputera i dane klientów przekazuj tylko uzgodnionym prywatnym kanałem.
